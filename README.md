# conhe-a-o-seu-signo
Conheça o Seu Signo

Site simples e moderno para descobrir o signo do zodíaco pelo nome e pela data de nascimento.

O resultado aparece na tela e também pode ser lido em voz alta no navegador.

Como usar





Abra o arquivo index.html no Chrome ou no Edge.



Digite o seu nome.



Escolha o dia, o mês e o ano de nascimento.



Clique em Revelar meu signo.



Leia o resultado ou clique em Ouvir resultado.

Também dá para:





compartilhar o texto do resultado



comparar a energia com um amigo



ver a roda dos 12 signos

O que o projeto mostra





Nome da pessoa no resultado
Exemplo: Emmanus, o seu signo é Capricórnio...



Símbolo e nome do signo



Datas do signo



Elemento, qualidade, planeta e cor da sorte



Frases leves de personalidade



Compatibilidade simples com um amigo

Arquivos





index.html — o site inteiro (HTML, CSS e JavaScript no mesmo arquivo)



README.md — este texto

Como colocar no GitHub





Crie um repositório público.



Envie o index.html e este README.md.



Em Settings → Pages, escolha a branch main e a pasta / (root).



Espere um ou dois minutos.



O site abre em:

https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

Como publicar no GitHub Pages





Abra o repositório.



Clique em Settings.



No menu esquerdo, clique em Pages.



Em Source, escolha Deploy from a branch.



Branch: main



Pasta: / (root)



Clique em Save.

Tecnologias





HTML



CSS



JavaScript



Web Speech API (voz do navegador)

Não precisa instalar nada. É só abrir o index.html.

Observações





A voz depende do navegador. No Chrome e no Edge costuma funcionar melhor.



Se a voz não iniciar sozinha, clique em Ouvir resultado.



Este projeto usa o signo solar pela data de nascimento.
